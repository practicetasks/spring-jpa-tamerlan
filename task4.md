# Задача

#### PUT /categories/{id} - обновление категорий
- Обновляем название категорий - если не пустое
- Обновляем название характеристики - если есть id у объекта
  - иначе создаем характеристику 
```json
{
  "name": "НОВОЕ НАЗВАНИЕ КАТЕГОРИЙ",
  "attributes": [
    {
      "id": 1,
      "name": "НОВОЕ НАЗВАНИЕ ХАРАКТЕРИСТИКИ"
    },
    {
      "name": "НОВОЕ НАЗВАНИЕ ХАРАКТЕРИСТИКИ 2"
    }
  ]
}
```

тело ответа
```json
{
  "id": 1,
  "name": "НОВОЕ НАЗВАНИЕ КАТЕГОРИЙ",
  "attributes": [
    {
      "id": 1,
      "name": "НОВОЕ НАЗВАНИЕ ХАРАКТЕРИСТИКИ"
    },
    {
      "id": 2,
      "name": "ХАРАКТЕРИСТИКА2"
    },
    {
      "id": 3,
      "name": "ХАРАКТЕРИСТИКА3"
    },
    {
      "id": 4,
      "name": "НОВОЕ НАЗВАНИЕ ХАРАКТЕРИСТИКИ 2"
    }
  ]
}
```
