# Задача

1. Создать класс `User`
2. Создать `UserRepository`
3. Создать `UserController`



### Эндпойнты
- `GET /users` - получить список пользователей
- `GET /users/{id}` - получить пользователя по id
- `POST /users` - создание пользователя
    - условие:
      - нельзя создать пользователя, если логин пустой или содержит пробел, минимально должен быть 2 символа
      - нельзя создать пользователя, если пароль пустой, минимально должен быть 8 символа и одна заглавная буква
      - нельзя создать пользователя, если роль не указан
      - _нельзя создать пользователя, если логин занят_
    - тело запроса 
    ```json
    {
        "login": "ЛОГИН",
        "role": "USER",
        "password": "ПАРОЛЬ"
    }
    ```
    - тело ответа
    ```json
    {
        "id": 1,
        "login": "ЛОГИН",
        "role": "USER",
        "password": "ПАРОЛЬ",
        "createdAt": "2026-05-25T21:27:33"
    }
    ```
- `PATCH /users?id={id}` - обновление пользователя по id
    - условие:
        - обновляем то, что указано в теле, остальное не трогаем
        - _нельзя обновить на занятый логин_
    - тело запроса
    ```json
    {
        "login": "НОВЫЙ ЛОГИН"
    }
    ```
    - тело ответа
    ```json
    {
        "id": 1,
        "login": "НОВЫЙ ЛОГИН",
        "role": "USER",
        "password": "ПАРОЛЬ",
        "createdAt": "2026-05-25T21:27:33"
    }
    ```
