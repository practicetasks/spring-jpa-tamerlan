# Задача

#### POST /categories - создание категорий
тело запроса
```json
{
  "name": "НАЗВАНИЕ КАТЕГОРИЙ",
  "attributes": [
    "ХАРАКТЕРИСТИКА1",
    "ХАРАКТЕРИСТИКА2",
    "ХАРАКТЕРИСТИКА3"
  ]
}
```

тело ответа
```json
{
  "id": 1,
  "name": "НАЗВАНИЕ КАТЕГОРИЙ",
  "attributes": [
    {
      "id": 1,
      "name": "ХАРАКТЕРИСТИКА1"
    },
    {
      "id": 2,
      "name": "ХАРАКТЕРИСТИКА2"
    },
    {
      "id": 3,
      "name": "ХАРАКТЕРИСТИКА3"
    }
  ]
}
```
